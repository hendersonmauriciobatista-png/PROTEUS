# Sistema De Análise De Água

## Visão Geral

O Sistema De Análise De Água é uma aplicação destinada ao monitoramento e visualização de parâmetros básicos de qualidade da água.

O sistema permite observar indicadores ambientais, comparar medições com limites configurados e apresentar resultados de forma clara e rastreável.

## Objetivo

Fornecer uma plataforma simples para acompanhamento de parâmetros de qualidade da água, apoiando atividades educacionais, demonstrativas e de observação ambiental.

## Funcionalidades Atuais

* Monitoramento de pH
* Monitoramento de Turbidez
* Monitoramento de Oxigênio Dissolvido (OD)
* Monitoramento de Temperatura
* Monitoramento de Agrotóxicos
* Classificação automática de conformidade
* Atualização dinâmica dos dados simulados
