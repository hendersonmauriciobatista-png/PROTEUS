# GP-REM-01 — Checklist de Pendências Remanescentes

## Controle

| Campo | Registro |
| --- | --- |
| Data-base | 28/07/2026 |
| Versão | 1.0 |
| Autoria | Produzido por agente documental sob execução da GP-REM-01; autoria intelectual institucional não atribuída |
| Finalidade | Controlar condições comprovadamente necessárias para futura recertificação |

## IMP-01 — Baseline

- [ ] Delimitar o conjunto institucional autorizado para consolidação.
- [ ] Separar documentação institucional de código, dados, mídia e outros escopos.
- [ ] Confirmar que todos os documentos obrigatórios integram o índice Git.
- [ ] Validar ausência de arquivos adicionais.
- [ ] Consolidar a baseline por processo autorizado.

## IMP-02 — Autoria e titularidade

- [ ] Reunir evidências de autoria intelectual por ativo.
- [ ] Identificar autores mediante instrumento autorizado.
- [ ] Formalizar titularidade em documento próprio.
- [ ] Distinguir autoria, titularidade, representação e propriedade jurídica.

## IMP-03 — Licenciamento

- [ ] Submeter política de licenciamento à autoridade competente.
- [ ] Definir ativos abrangidos e exclusões.
- [ ] Identificar materiais e direitos de terceiros.
- [ ] Registrar a decisão canônica aplicável.

## IMP-04 — Proponente e campus

- [ ] Definir a forma do proponente.
- [ ] Registrar dados comprovados do proponente.
- [ ] Escolher o campus destinatário.
- [ ] Confirmar oficialmente chamada, vagas e procedimento do campus.

## IMP-05 — Autorização

- [ ] Preparar versão exata candidata ao envio.
- [ ] Obter aprovação institucional dessa versão.
- [ ] Obter decisão específica autorizando a submissão.
- [ ] Preservar os limites de atuação do representante definidos na DI-01.

## IMP-06 — Formulário

- [ ] Confirmar o formulário vigente do campus escolhido.
- [ ] Reunir somente dados e evidências documentados.
- [ ] Preencher o formulário sob autorização.
- [ ] Reconciliar todas as afirmações com Inventário e Dossiê.
- [ ] Revisar a declaração de veracidade e os termos antes do aceite autorizado.

## IMP-07 — Requisitos externos

- [ ] Obter o inteiro teor oficial do regulamento vigente.
- [ ] Resolver os 10 requisitos `ATENDE PARCIALMENTE` da GP-CLS-06.
- [ ] Resolver os 12 requisitos `NÃO ATENDE` da GP-CLS-06.
- [ ] Confirmar categoria de proponente, se não expressamente coberta.
- [ ] Submeter nível e elegibilidade à avaliação oficial da sprinT.

## Estado

**7 IMPEDIMENTOS REMANESCENTES.**

Este checklist não atribui autoridade, não autoriza envio e não substitui evidências, decisões ou confirmações externas.
