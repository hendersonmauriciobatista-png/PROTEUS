# GP-DI-04 — Mapa de Dependências Documentais do Proponente

## Controle

| Campo | Registro |
| --- | --- |
| Versão | 1.0 |
| Data | 28/07/2026 |
| Natureza | Preparatória; não decisória |

## Fluxo

```text
GP-CLS-06 — categorias e limites externos conhecidos
        +
DI-01 — representação
        +
DI-DEC-02 — autoria e titularidade provisória
        +
DI-DEC-03 — política provisória
        ↓
escolha institucional do campus
        ↓
confirmação oficial das categorias admissíveis
        ↓
reunião dos documentos da pessoa ou entidade considerada
        ↓
deliberação institucional sobre proponente
        ↓
documento canônico da decisão
        ↓
incorporação documental
        ↓
formulário e pacote candidato
        ↓
aprovação da versão e autorização específica de envio
```

## Precedências

| Dependência | Motivo |
| --- | --- |
| Campus e chamada vigentes | Determinam requisitos externos aplicáveis ao proponente. |
| Confirmação da categoria | Impede presumir admissibilidade, especialmente de MEI. |
| Documentos pessoais ou jurídicos | Comprovam existência, identidade e dados da forma escolhida. |
| Relação com os ativos | Sustenta legitimidade institucional sem confundir papéis. |
| Decisão canônica | Constitui a autoridade primária do proponente. |
| Incorporação posterior | Atualiza consumidores sem ampliar a decisão. |

## Documentos consumidores após eventual decisão

| Documento | Atualização dependente |
| --- | --- |
| `OFFICIAL_DOCUMENTARY_BASELINE.md` | Referência ao documento canônico, sem alterar o perímetro |
| `INSTITUTIONAL_PROFILE.md` | Identificação institucional estritamente autorizada |
| `INSTITUTIONAL_MAP.md` | Papel do proponente, se determinado |
| `EXECUTION_PLAN.md` | Forma, identidade e dependências administrativas |
| `PRESENTATION_OUTLINE.md` | Identificação autorizada para apresentação |
| `INSTITUTIONAL_ASSET_INVENTORY.md` | Referência à decisão, sem alterar titularidade |
| `EVIDENCE_DOSSIER.md` | Evidência canônica do proponente |
| `PACKAGE_RECONCILIATION_REPORT.md` | Estado factual da pendência |
| `ADMINISTRATIVE_SUBMISSION_CHECKLIST.md` | Forma e dados comprovados |
| `AGIPI_REQUIREMENTS_TRACEABILITY_MATRIX.md` | Reclassificação somente conforme evidência oficial |
| formulário oficial | Dados do proponente após confirmação do campus |

## Limite

A definição de proponente não escolhe campus, não aprova formulário e não autoriza submissão. Essas etapas permanecem autônomas.
