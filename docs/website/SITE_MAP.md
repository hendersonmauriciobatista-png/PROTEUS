# Mapa Oficial Do Website Institucional Do PROTEUS

## Objetivo

Definir o mapa oficial de navegacao do Website Institucional do PROTEUS, refletindo exclusivamente conteudos existentes e documentados.

## Mapa De Navegacao

```text
Home
|
|-- Sobre o PROTEUS
|-- Plataforma
|-- Funcionalidades
|-- Arquitetura
|-- Casos de Uso
|-- Documentacao
|-- Demonstracao
|-- Roadmap
|-- Historia
`-- Contato
```

## Paginas Principais

| Pagina | Fonte documental | Responsabilidade |
| --- | --- | --- |
| Home | Kit Institucional, PI-01 | Responder o que e o PROTEUS e orientar o visitante. |
| Sobre o PROTEUS | Apresentacao Institucional | Explicar origem, missao, visao, valores e proposito. |
| Plataforma | One Page, Ficha Tecnica | Apresentar a plataforma em linguagem executiva. |
| Funcionalidades | One Page, Ficha Tecnica | Listar funcionalidades implementadas. |
| Arquitetura | AC-01, Visao Arquitetural Executiva | Explicar camadas e fluxo em alto nivel. |
| Casos de Uso | Casos De Uso Institucionais | Apresentar usos atuais e demonstraveis. |
| Documentacao | Branding, Institucional, Arquitetura, Historia, Roadmap | Organizar acesso aos documentos publicos. |
| Demonstracao | Roteiro Oficial De Demonstracao | Orientar apresentacoes institucionais. |
| Roadmap | ROADMAP.md | Expor estado e evolucao documentada do projeto. |
| Historia | HISTORY.md | Expor memoria evolutiva do CASE-01. |
| Contato | Estrutura futura | Definir canais institucionais sem dados pessoais. |

## Hierarquia Recomendada

### Primeiro Nivel

* Home.
* Sobre o PROTEUS.
* Funcionalidades.
* Arquitetura.
* Documentacao.
* Contato.

### Segundo Nivel

* Plataforma.
* Casos de Uso.
* Demonstracao.
* Roadmap.
* Historia.

## Conteudos Nao Incluidos

Nao devem ser criadas paginas para:

* funcionalidades futuras nao implementadas;
* API publica inexistente;
* portal de usuarios inexistente;
* login web inexistente;
* banco de dados ou backend inexistente;
* sensor real ou coleta fisica como capacidade existente;
* conformidade legal automatica.

## Veredito

O mapa oficial cobre as quatro perguntas fundamentais do website e permanece aderente ao estado atual do PROTEUS.
