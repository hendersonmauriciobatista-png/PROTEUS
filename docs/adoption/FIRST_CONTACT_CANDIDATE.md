# O Que Será Apresentado

* PRESENTATION.md
* QUICK_START.md
* USER_GUIDE.md
* FEEDBACK_FORM.md

---

# O Que Não Será Solicitado

* compra;
* contratação;
* parceria institucional;
* dados sensíveis;
* bases de dados internas;
* integração com sistemas existentes.

---

# Critério De Sucesso

Será considerado sucesso se ocorrer pelo menos um dos eventos abaixo:

* resposta positiva ao contato;
* demonstração agendada;
* instalação para avaliação;
* feedback estruturado recebido.

---

# Riscos Identificados

* ausência de resposta;
* encaminhamento para setor inadequado;
* indisponibilidade para avaliação;
* interpretação equivocada como proposta comercial.

---

# Mitigações

* comunicação curta;
* foco em validação;
* linguagem não comercial;
* utilização de dados simulados;
* respeito ao tempo do avaliador.
