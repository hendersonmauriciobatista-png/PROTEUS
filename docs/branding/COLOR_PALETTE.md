# Paleta Oficial Do PROTEUS

Registrar as cores oficiais da identidade visual do PROTEUS para aplicacao em interfaces, documentos, apresentacoes, publicacoes e materiais institucionais.

Os valores CMYK sao aproximados e devem ser validados com fornecedor grafico quando houver impressao profissional.

## Regras De Uso

* Usar o Ciano PROTEUS apenas para identidade, destaque tecnico e hierarquia visual.
* Nao usar ciano como alerta de erro.
* Usar verde somente para normalidade, estabilidade ou desempenho adequado.
* Usar laranja e dourado para atencao, cautela e contexto intermediario.
* Usar vermelho somente para criticidade ou risco.
* Evitar novas cores sem justificativa institucional documentada.
* Preservar contraste minimo em interfaces, slides e relatorios.
* Em fundo claro, usar azul noite ou azul de navegacao para texto e marca.
* Em fundo escuro, usar ciano, cinza texto e branco controlado para leitura.
