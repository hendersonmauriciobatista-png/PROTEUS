# Icones Oficiais Do PROTEUS

## Objetivo

Definir diretrizes para favicon, icone de aplicativo e iconografia institucional do PROTEUS.

## Principio

Icones oficiais devem derivar do simbolo institucional aprovado. Esta PI nao cria simbolo novo nem converte a marca em icone por inferencia.

## Ativos Oficiais Reservados

```text
assets/icons/favicon.ico
assets/icons/favicon.svg
assets/icons/app_icon.ico
assets/icons/app_icon.png
```

Esses arquivos devem ser adicionados somente quando exportados a partir do simbolo oficial.

## Tamanhos Recomendados

| Ativo | Tamanhos |
| --- | --- |
| Favicon ICO | 16x16, 32x32, 48x48 |
| Favicon SVG | Vetorial responsivo |
| App icon ICO | 16x16, 32x32, 48x48, 256x256 |
| App icon PNG | 256x256, 512x512, 1024x1024 |

## Regras De Uso

* Usar o simbolo oficial simplificado em tamanhos pequenos.
* Evitar textos longos em favicons.
* Preservar contraste em fundo claro e escuro.
* Nao criar icones decorativos que parecam logo alternativo.
* Nao usar emoji, pictograma generico ou simbolo externo como marca oficial.

## Iconografia De Interface

Icones funcionais de interface devem seguir a linguagem tecnica do produto:

* linhas simples;
* baixo ornamento;
* contraste suficiente;
* significado operacional claro;
* consistencia com a paleta oficial.
