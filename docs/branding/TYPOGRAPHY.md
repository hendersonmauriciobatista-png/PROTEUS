# Tipografia Institucional Do PROTEUS

## Objetivo

Definir o uso tipografico oficial da marca PROTEUS em aplicacao, documentacao, dashboards, apresentacoes e materiais institucionais.

## Regra Principal

A tipografia da marca aprovada deve ser preservada. Esta PI nao substitui, redesenha ou altera a tipografia do logotipo oficial.

## Tipografia Por Contexto

| Contexto | Tipografia oficial |
| --- | --- |
| Marca / logotipo | Tipografia aprovada no logo oficial, sem substituicao. |
| Aplicacao desktop | Sans-serif padrao do sistema operacional. |
| Dashboard | Sans-serif padrao do sistema operacional, com hierarquia clara. |
| Documentacao tecnica | Fonte padrao do renderizador Markdown. |
| Relatorios e blocos tecnicos | Consolas ou monoespacada equivalente quando favorecer alinhamento. |
| Apresentacoes | Sans-serif institucional limpa, preferencialmente a fonte padrao do ambiente de apresentacao. |
| Website | Sans-serif web segura ou familia equivalente, preservando legibilidade e sobriedade. |

## Hierarquia Recomendada

| Nivel | Uso | Diretriz |
| --- | --- | --- |
| H1 | Capa, nome do produto, titulo principal | Peso forte, alto contraste, uso parcimonioso. |
| H2 | Secao principal | Peso medio/forte, preferencialmente com cor institucional. |
| H3 | Subsecao | Peso medio, sem competir com H1/H2. |
| Corpo | Texto corrido | Leitura simples, sem efeitos. |
| Legenda | Metadados, fonte, data | Tamanho menor e cor auxiliar. |
| Codigo/dados | Dados tecnicos, relatorios, exemplos | Monoespacada. |

## Restricoes

E proibido:

* alterar a tipografia da marca;
* usar fontes decorativas em materiais institucionais;
* misturar muitas familias tipograficas;
* aplicar sombra, contorno ou efeitos no texto da marca;
* reduzir texto a ponto de comprometer leitura;
* usar caixa alta extensiva em textos longos.
